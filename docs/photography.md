## Intentionally withheld

Existing source images are explicitly described as generated in `initialData.ts`. These have been removed from the public homepage, product list, product detail and media gallery presentation. Existing image data and files remain intact so that stored records are not destructively migrated. A real rib steak is not substituted for unrelated products.

The catalogue is intentionally text-led until product-specific photographs can be verified. This is preferable to putting an inaccurate or generated picture beside a product.
